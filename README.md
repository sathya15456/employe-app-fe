## Angular Setup Guide (v20.3.24)

This section explains how to install Node.js, set up Angular CLI, and verify your Angular version.

### 1. Install Node.js

Angular requires Node.js to run.

**Steps:**

* Go to: https://nodejs.org
* Download the LTS (Long Term Support) version
* Install using the setup wizard

**Verify installation:**

```bash
node -v
npm -v
```

---

### 2. Install Angular CLI

```bash
npm install -g @angular/cli
```

---

### 3. Check Angular CLI Version

```bash
ng version
```

or

```bash
ng v
```

---

### 4. Create a New Angular Project

```bash
ng new employee-app
cd employee-app
```

---

### 5. Run the Application

```bash
ng serve
```

Open browser:

```
http://localhost:4200/
```

---

## Development Server

## Troubleshooting

**If `ng` is not recognized:**

* Restart terminal
* Check npm global path

**Fix version mismatch:**

```bash
npm uninstall -g @angular/cli
npm install -g @angular/cli@20.3.24
```
